## GDELT live status

GDELT returned live data through the adapter on 2026-10-11 (19 headlines, 17 days of coverage). Earlier in the same session it answered HTTP 429 for several minutes, even to requests spaced 20–30 s apart. The dashboard reports those periods as `RATE_LIMITED`, and the 60-second local cooldown stops further calls during that time.
